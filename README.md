# 🏡 Proyecto de Cerramiento Autoportante de Patio (15 m²)

Bienvenido al repositorio oficial del proyecto de cerramiento y adecuación de patio trasero para vivienda unifamiliar.

Este espacio está diseñado para servir como pliego de condiciones técnicas y canal de comunicación con proveedores e instaladores de carpintería metálica, aluminio y acristalamiento.

---

## 📌 Resumen Ejecutivo del Proyecto

* **Ubicación:** Torrelodones, Madrid (Clima de sierra: alta exigencia de aislamiento térmico, resistencia a viento y cargas de nieve).
* **Superficie total:** 15 m² (5,00 m de ancho Este-Oeste × 3,00 m de profundidad Norte-Sur).
* **Altura libre:** 2,30 m.
* **Objetivo:** Reconversión de patio exterior en estancia habitable, luminosa y climatizada todo el año, anexa a la cocina (comedor informal, zona de lectura y esparcimiento).
